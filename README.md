# Recon Opus – Floor Pilot

Recon Opus is a mobile-first automotive reconditioning operations platform.

The Floor Pilot focuses exclusively on technicians and production employees working on the shop floor.

## Pilot Goals

- Horizontal swiping between departments
- Large vehicle cards
- Department-specific one-tap status updates
- Proactive technician check-ins
- Minimal typing
- Premium automotive user experience

Current phase:
Production-side mobile pilot only.
